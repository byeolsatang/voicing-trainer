MIDIキーボードの繋ぎ方ガイド

Rootless Voicing Trainer で実際の鍵盤を使うための接続手順です。お使いの機器に合う接続方法を選んでください。

1必要なもの

・MIDIキーボード/MIDIコントローラー(USB接続できるものが最も簡単です)
・USBケーブル(機器によりUSB-A / USB-B / USB-C)
・Web MIDI APIに対応したブラウザ(Chrome / Edge / Opera を推奨。Safari・Firefoxは標準では非対応です)

2接続タイプを選ぶ

A. USB接続のキーボード/コントローラー(最も一般的)

MIDIキーボード
→
USBケーブル
→
PC

USBケーブルでPCに挿すだけです。最近の機器はほぼ「クラスコンプライアント」なので、追加のドライバーは不要です。

B. 古いタイプ(MIDI端子=丸い5pin DINのみ)のキーボード

MIDIキーボード
→
5pin DIN
→
USB-MIDI
インターフェース
→
USB
→
PC

USB端子がない古いシンセ/キーボードの場合、「USB-MIDIインターフェースケーブル」(数百〜数千円程度)が別途必要です。MIDI OUT(キーボード側)とUSB-MIDIインターフェースのMIDI INを接続します。

C. Bluetooth MIDIキーボード

MIDIキーボード
⤳
Bluetooth
⤳
PC

OSのBluetooth設定からキーボードをペアリングします。ペアリング後は通常のMIDI入力として認識されます。接続が不安定な場合は本体との距離を近づけてください。

3ブラウザ側の設定手順

  • キーボードをPCに接続する(上記の方法で)
  • Chrome / Edge などでこのトレーニングアプリ(index.html)を開く
  • 初回アクセス時に「MIDIデバイスへのアクセスを許可しますか」というダイアログが出たら許可を選ぶ
  • 設定画面のプルダウンに機器名が表示されたら選択する(1台のみなら自動で選択されます)
  • ドットが緑色になれば接続完了。鍵盤を弾くと反応します

下のプルダウンでMIDI機器を選び、実際に鍵盤を弾いてみてください。正しく繋がっていれば音名が表示されます。

5うまく繋がらない時

プルダウンに機器名が出てこない

USBケーブルを挿し直す/別のUSBポートに挿してみてください。ブラウザのページを再読み込み(リロード)すると再検出されることがあります。OS側で機器が認識されているかも確認してください(Mac: 「Audio MIDI設定」アプリ / Windows: デバイスマネージャー)。

許可のダイアログが出ない、または弾いても反応しない

このHTMLファイルを直接ダブルクリックで開いている(アドレスバーが file:// で始まる)場合、ブラウザによってはMIDIアクセスがブロックされることがあります。その場合は下記「ローカルサーバーで開く」を試してください。

DAWなど他のソフトを使っている

DAWや他の音楽制作ソフトがMIDIデバイスを排他的に使用している場合、ブラウザ側で認識できないことがあります。一度そのソフトを閉じてから試してください。

使っているブラウザで動かない

Web MIDI APIはSafariやFirefoxでは標準で対応していません(Firefoxは about:config で実験的に有効化できる場合があります)。Chrome、Edge、Operaのいずれかでお試しください。

6ローカルサーバーで開く方法(file://でうまくいかない場合)

voicing-trainer.html と midi-setup-guide.html を同じフォルダに置いた状態で、以下のいずれかを実行してください。

Mac / Linux(ターミナル)

cd フォルダのパス
python3 -m http.server 8000

Windows(コマンドプロンプト)

cd フォルダのパス
python -m http.server 8000

Node.jsがある場合

npx serve .

実行後、ブラウザで http://localhost:8000/voicing-trainer.html を開いてください。

このページの接続テストもブラウザ内だけで動作し、演奏データはどこにも送信されません。
